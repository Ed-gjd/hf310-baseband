# HF310 逆向与基带开发学习记录

从一台中兴微 ZX297520 方案的随身 WiFi(HF310)出发的一次完整技术探索:先补电信/无线原理(Erlang 高并发、全息 MIMO、合成孔径、相控阵),再做实机 Web API 逆向与 PCB 分析,延伸到 Quectel EC25 开发路径与 4G 基带芯片创业分级。

> 状态:调研记录 · 2026-09-02
> 定位:硬件 / 嵌入式方向调研存档

## 覆盖内容

- **原理七篇**:Erlang / 全息 MIMO(6G)/ 合成孔径 / 相控阵 —— 从易到难
- **HF310 实机逆向**:USB 枚举 → Web API 登录与命令提取 → 按键组合测试 → PCB 分析 → CH341A 读 Flash 路径
- **Quectel EC25 开发**:AT 命令 / quectel-CM / qmicli / MiFi 产品开发六阶段
- **基带芯片创业**:做 EC25 的四个级别、最接近的学习路径、细分创业机会与认证/量产成本
